GharSeRent – Community Rental Platform

📌 Project Description

GharSeRent is a full-stack web application built using the MEAN stack (MongoDB, Express.js, Angular, Node.js).
The platform enables users to rent and lend items securely within their community. Users can list items, send rental requests, and manage approvals efficiently. To ensure privacy and security, contact details are shared only after the owner approves a rental request.
The application is designed with a responsive UI, secure authentication, and smooth request handling.

✨ Features

User authentication with role-based access (Owner / Renter)

List items for rent and manage inventory

Rental request system with approval workflow

Contact details shared only after request approval

Flexible rental duration selection (hours or days)

Fully responsive design for mobile and desktop

🛠️ Tech Stack

Frontend: Angular, HTML, CSS, Bootstrap
Backend: Node.js, Express.js
Database: MongoDB
Tools & Utilities: Git, GitHub, Postman, VS Code
