Project Title:

GharSeRent – Community Rental Platform

Description:

GharSeRent is a full-stack web application built using the MEAN stack (MongoDB, Express.js, Angular, Node.js).
It allows users to list, rent, and return items securely within their community.
Users can specify rental duration (hours or days), and owners can approve rental requests before sharing contact details. 
The platform focuses on security, responsive UI, and real-time request handling.

Features:

User authentication and role-based access (Owner / Renter)

List items for rent and manage inventory

Request system for renting items with approval workflow

Contact details shared only after approval

Fully responsive design for mobile and desktop

Tech Stack:

Frontend: Angular, HTML, CSS, Bootstrap

Backend: Node.js, Express.js

Database: MongoDB

Other Tools: Git, GitHub, Postman, VS Code
